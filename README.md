# 봉곡 UOI 매핑

배포: https://hehegs-beep.github.io/bonggok-uoi-map/

1~6학년 구글 시트를 읽어 단원별·주제별·성취기준별·요약으로 보여 줍니다. 원본은 학년별 구글 시트입니다. GitHub에는 화면과 교육과정 참고 자료를 저장합니다.

## 읽기와 저장

- 필터로 숨겨진 행까지 포함하는 전체 CSV를 읽고 학년으로 구분합니다. 기본 1분마다 갱신합니다.
- 주제 배지를 누르면 6개 주제와 미지정을 선택할 수 있습니다. 구글 연결 후 원본 편집 권한으로 G열에 직접 저장합니다. Apps Script는 사용하지 않습니다.
- 저장 직전에 원본 행의 A:G 값을 비교합니다. 변경된 행이면 새로고침을 안내합니다. Sheets API는 원자적 조건부 쓰기를 제공하지 않으므로 동시 저장을 완전히 잠그지는 않습니다.
- 로그인 토큰은 메모리에만 보관합니다. 캐시·필터·사용자 지정 CSV는 학년별로 나누어 저장합니다.
- 다른 학년 행은 표시하거나 변경하지 않습니다.

## 6학년

같은 파일 안의 `웹앱 연동` 탭을 수정 기준으로 사용합니다. 최초 구성 버튼은 구글 연결 후 `1학기 종합`과 `(수정중)2학기 종합`을 읽습니다. 기존 종합·과목별 탭은 변경하지 않습니다.

- 실제 병합 범위 안에서만 값을 펼칩니다. 빈 주제를 무조건 앞 행의 값으로 채우지 않습니다.
- 성취기준 하나당 한 행으로 교과·학년·학기·단원·영역·성취기준·주제를 정리합니다.
- 학기는 실제 UOI 포함 메모, 학기 열 메모, 단원 학기 메모 순으로 반영합니다. 명시된 메모가 없으면 종합 탭의 학기를 쓰고 연간 단원은 확인 사항으로 표시합니다. 같은 학기·단원·영역·코드·주제·운영 여부가 같은 행은 합치되 원문과 출처를 모두 보존합니다. 서로 다른 주제나 영역은 합치지 않습니다.
- 차시(단원 기준), 학습 내용, 운영 여부, 교과서 학기 메모, 확인 사항, 원본 탭·행·행 ID·원문 전체를 보존합니다. 차시는 성취기준별로 합산하지 않습니다.
- 기존 연동 탭이 있으면 다시 생성하거나 덮어쓰지 않습니다.
- 이후 수정은 연동 탭에서 합니다. 기존 종합·과목별 탭과 자동으로 동기화되지 않습니다.

## 교육과정 해설

상세창에는 해당 성취기준의 해설 원문과 직접 관련된 고려 사항만 표시합니다. 1~6학년 모두 동일한 구성이며, 개별 해설이나 선택된 고려 사항이 없는 구역은 숨깁니다.

- 자료 소개, 출처 링크, 매핑 분류, 영역 공통 전체 목록, 중복 시트 해설은 표시하지 않습니다.
- 고려 사항은 같은 공식 영역 안에서 성취기준의 구체적인 내용과 활동을 비교해 최대 3개를 선택합니다. 원문이 코드를 지정한 항목을 우선하며, 그 밖의 항목은 과목별 내용 기준으로 연결합니다.
- 넓은 의미의 공통 지도 안내와 용어 목록은 제외합니다. 분수/소수, 계산/개념, 넓이/부피, 영어 듣기/읽기처럼 내용이 다른 항목을 구분합니다.
- 출처, 원문 전체, 연결 기준은 `curriculum-data.js` 안에 보존합니다. 화면 검색은 실제 표시하는 해설과 선택된 고려 사항을 사용합니다.

원문 입력은 `tmp/pdfs/`에 두며 공개 저장소에는 올리지 않습니다. 전체 자료를 다시 만들 때에는 `scripts/build_curriculum.py`, `scripts/build_upper_guidance.py`, `scripts/build_focused_guidance.py` 순서로 실행합니다. 원문 문단 추출은 `scripts/extract_curriculum_hwp.py`를 사용합니다. 통합교과 원문은 교육부 고시 제2022-33호 게시물의 붙임3에서 받은 별책15 한글 파일을 `tmp/pdfs/book15.hwp`에 둡니다. 연결 근거를 검토할 수 있는 별도 결과는 `tmp/focused-guidance-review.json`에 생성됩니다.

## 배포와 설정

`main` 브랜치를 GitHub Pages가 배포합니다. 별도 빌드가 없습니다. 설정에서 새로고침 주기·학년별 CSV·구글 로그인 연결 ID를 관리합니다. 공개 CSV를 읽지 못할 때에는 구글 연결이 필요합니다.

파일·탭은 `index.html`의 `SOURCES`에 정의합니다. 6학년 신규 연동 탭 ID는 `16061016`입니다.
