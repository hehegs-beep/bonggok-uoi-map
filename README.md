# 봉곡 1학년 UOI 매핑 뷰어

구글 시트 「1학년 성취기준(봉곡 UOI맵핑용)」의 **「1학년 성취기준」 탭(gid=0)** 을 실시간으로 읽어
단원별 · 주제별 · 성취기준별 · 요약 네 가지 화면으로 보여주는 단일 HTML 앱입니다.
시트에서 값을 고치고 저장하면 앱이 다음 확인 주기(기본 1분)에 자동으로 반영합니다.

파일은 `index.html` 하나뿐이고, 빌드나 서버 설치가 필요 없습니다.

## 1. 여는 방법

| 방법 | 동작 | 비고 |
|---|---|---|
| `index.html` 더블클릭 | 브라우저가 `file://`로 열고, 시트를 **JSONP** 방식으로 읽음 | 가장 간단. 공유하려면 파일을 보내야 함 |
| 정적 호스팅에 올리기 (GitHub Pages, Netlify Drop 등) | 시트를 **CSV fetch** 방식으로 읽음 | 주소 하나로 동료와 공유 가능 |
| Google Apps Script 웹앱 | 학교 구글 계정으로만 접근하도록 제한 가능 | 아래 5절 참고 (미검증) |

전송 방식은 앱이 자동으로 고릅니다. `file://`이면 JSONP, 웹 서버면 CSV fetch를 먼저 시도하고 실패하면 JSONP로 넘어갑니다.
필요하면 설정(톱니바퀴)에서 강제로 바꿀 수 있습니다.

> claude.ai 아티팩트로는 올릴 수 없습니다. 아티팩트 페이지는 외부 사이트(docs.google.com) 요청이 차단되어 실시간 연동이 동작하지 않습니다.

## 2. 시트가 지켜야 할 규칙

앱은 **머리글 이름**으로 열을 찾습니다. 열 순서를 바꾸거나 열을 추가해도 괜찮습니다.

| 머리글에 포함될 글자 | 예 | 처리 |
|---|---|---|
| 교과 | 국어, 수학, 바른 생활 … | 섹션 · 필터 |
| 학년 | 1 | 학기 값이 숫자 하나일 때 보조로 사용 |
| 학기 | 1-1, 1-2 | 날짜로 바뀌어 있어도(2026-01-02) 표시값 `1-2`로 읽음 |
| 단원 | 4단원, 한글 놀이, 학교 … | 단원 카드. `N단원`은 번호순, 통합교과 단원은 학교→사람들→우리나라→탐험→하루→약속→상상→이야기 순 |
| 영역 | 듣기·말하기, 수와 연산 … | 필터 |
| 성취기준 (해설 제외) | `[2국01-01] 중요한 내용이나 …` | **대괄호 코드**로 같은 성취기준을 묶음. 코드가 없으면 문장 자체로 묶음 |
| 주제 | 우리는 누구인가 | 6개 한글 이름, 약어(WWA 등), 영문명 모두 인식. 쉼표로 여러 개 가능. 비우면 「미지정」 |
| 해설 | 긴 설명 또는 `해당 없음` | `해당 없음`은 해설 없음으로 처리 |

인식하는 초학문적 주제 6개:

| 약어 | 한글 | 영문 |
|---|---|---|
| WWA | 우리는 누구인가 | Who we are |
| WWAPT | 우리가 속한 공간과 시간 | Where we are in place and time |
| HWEO | 우리 자신을 표현하는 방법 | How we express ourselves |
| HTWW | 세계가 돌아가는 방식 | How the world works |
| HWOO | 우리 자신을 조직하는 방식 | How we organize ourselves |
| STP | 우리 모두의 지구 | Sharing the planet |

목록에 없는 주제 이름을 적으면 회색 배지로 그대로 표시됩니다.

그 밖에:

- **시트 공개 설정**은 「링크가 있는 모든 사용자 – 뷰어」 이상이어야 합니다 (현재 그렇게 되어 있습니다). 비공개로 바꾸면 앱이 읽지 못합니다.
- 「초학문적 주제별 성취기준」, 「성취기준별」 탭은 앱이 원본에서 자동 계산하므로 더 이상 손으로 맞출 필요가 없습니다.
- 2학년 행을 같은 탭에 추가하면 학기 `2-1`, `2-2`가 자동으로 생깁니다.
- 탭 순서를 바꿔도 gid는 변하지 않습니다. 다른 탭을 읽게 하려면 `index.html`의 `CONFIG.gid` 값을 바꾸세요.

## 3. 동기화 동작

- 열 때 즉시 읽고, 기본 **1분마다**(탭이 보일 때만), 그리고 창으로 돌아올 때 다시 확인합니다.
- 내용이 바뀌면 화면을 다시 그리고 「시트 변경 사항을 반영했습니다」 알림을 띄웁니다.
- 상단 「새로고침」 버튼으로 즉시 확인할 수 있습니다.
- 마지막으로 읽은 데이터는 브라우저에 캐시되어, 네트워크가 끊겨도 마지막 상태를 보여줍니다 (상태 표시가 빨간색이 됨).
- gviz 주소는 시트 저장 후 보통 수 초 안에 반영됩니다. 「웹에 게시」 CSV 주소를 쓰면 구글 쪽에서 최대 5분 정도 늦게 반영될 수 있습니다.

## 4. 설정 (톱니바퀴 버튼)

- **CSV 주소**: 「파일 › 공유 › 웹에 게시」에서 받은 CSV 주소를 넣으면 그 주소를 읽습니다. 비워 두면 기본 gviz 주소를 씁니다.
- **전송 방식**: 자동 / CSV fetch만 / JSONP만.
- **자동 새로고침**: 30초 · 1분 · 3분 · 끄기.
- **캐시 지우기**: 저장된 마지막 데이터를 지웁니다.

설정과 필터, 마지막 화면은 이 브라우저에만 저장됩니다.

## 5. 배포 옵션

### GitHub Pages
저장소를 만들고 `index.html`을 올린 뒤 Settings › Pages에서 브랜치를 선택하면 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다.

### Netlify Drop
<https://app.netlify.com/drop> 에 이 폴더를 끌어다 놓으면 바로 주소가 생깁니다.

### Google Apps Script (미검증)
학교 구글 계정 사용자에게만 열고 싶을 때 쓸 수 있습니다.

1. <https://script.google.com> 에서 새 프로젝트를 만듭니다.
2. `Code.gs`에 아래를 넣습니다.
   ```js
   function doGet() {
     return HtmlService.createHtmlOutputFromFile('index')
       .setTitle('봉곡 1학년 UOI 매핑')
       .addMetaTag('viewport', 'width=device-width, initial-scale=1');
   }
   ```
3. 「파일 추가 › HTML」로 `index` 파일을 만들고 `index.html` 내용을 전부 붙여넣습니다.
4. 「배포 › 새 배포 › 웹 앱」에서 액세스 권한을 「조직 내 모든 사용자」로 두고 배포합니다.

## 6. 문제 해결

| 증상 | 원인 · 조치 |
|---|---|
| 「시트를 읽지 못했습니다」 | 시트 공개 설정 확인. 설정에서 전송 방식을 JSONP로 바꿔 보기 |
| 상태 표시가 빨간색, 옛 데이터 | 네트워크 또는 구글 응답 실패. 「새로고침」을 누르거나 잠시 후 다시 시도 |
| 성취기준이 두 줄로 따로 나옴 | 대괄호 코드가 다르거나 빠짐. 시트에서 `[2국01-01]` 형식 확인 |
| 주제가 회색 배지로 나옴 | 주제 이름 오타. 위 표의 한글 이름과 맞추기 |
| 학기가 이상하게 나옴 | 학기 셀이 날짜로 바뀐 경우 표시 형식을 「일반 텍스트」로 바꾸고 `1-1`로 입력 |
