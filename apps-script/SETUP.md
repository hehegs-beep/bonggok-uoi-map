# 구글 시트 편집 연결

1. 원본 구글 시트에서 확장 프로그램 → Apps Script를 엽니다.
2. Code.gs 내용을 이 폴더의 Code.gs로 바꿉니다.
3. HTML 파일을 추가해 이름을 Editor로 정하고 Editor.html 내용을 붙여넣습니다.
4. 배포 → 새 배포 → 웹 앱을 선택합니다.
5. **실행 사용자: 웹 앱에 액세스하는 사용자**로 설정합니다. 소유자로 실행하지 마세요. 사용자 각자의 구글 시트 권한을 사용합니다.
6. 액세스 권한은 학교 정책에 맞게 로그인한 사용자 또는 조직 사용자로 설정합니다. 편집할 선생님들에게 원본 시트 편집 권한을 부여합니다.
7. 배포하고 구글 권한 승인을 마친 뒤 /exec로 끝나는 배포 주소를 복사합니다.
8. 조회 웹앱 설정 → 구글 시트 편집창 주소에 입력하고 저장합니다. 이 설정은 브라우저별로 저장됩니다.
9. 성취기준 상세창 → 주제 수정 → 단원별 주제 선택 → 저장을 누릅니다.

서버에서 G열만 수정합니다. 저장 전에 A~F열과 기존 G열 값을 다시 비교합니다. 다른 사용자가 먼저 수정하거나 행이 이동하면 저장을 거절하고 새로 불러오도록 안내합니다. Apps Script의 잠금은 이 편집창끼리의 동시 저장을 직렬화하며, 시트에서 직접 수정하는 작업까지 잠그지는 않습니다.

처음 접속하는 선생님은 구글 로그인 및 권한 승인이 필요합니다. 배포 계정의 조직 정책에 따라 관리자의 허용이 필요할 수 있습니다. CSV 조회는 구글 캐시 때문에 저장 직후 표시까지 지연될 수 있습니다. 편집창의 ‘새로 불러오기’는 시트를 직접 읽어 확인합니다.

실제 배포 및 계정별 저장 권한은 사용자의 Google 계정에서 최종 확인해야 합니다.
